# Lanzamiento Inicial: MATICERTS.COM API v1.0.0 🚀

Nos complace anunciar la primera versión estable y pública de nuestra API RESTful para la gestión y emisión de certificados digitales.

Esta actualización principal incluye todas las capacidades funcionales necesarias para integradores externos.

<!--truncate-->

## ✨ Novedades

### 🔑 Seguridad y Autenticación
- **Personal Access Tokens (PAT)**: Implementación de la creación y gestión de tokens de larga duración para integraciones Machine-to-Machine.
- **OAuth 2.0 Integrado**: Soporte completo para flujos de login estándar para aplicaciones cliente.

### 📄 Gestión de Certificados
- Soporte para flujos **Zero-Touch** de generación y emisión vía PKCS#10.
- Descarga segura de archivos P7B y certificados ensamblados en formato P12.

### 🧪 Entorno Sandbox
- Activación de entorno completo de pruebas y simulación sin impacto real en producción.
- `MockViafirmaClient` disponible en el entorno Sandbox para pruebas continuas sin fricción.

## 🔒 Mejoras de Seguridad Recientes
- Se han eliminado todos los endpoints de administración interna de esta documentación pública para garantizar un flujo limpio a los integradores (Principio de Mínimo Privilegio).
- Ocultamiento de referencias a variables de entorno locales (ej. drivers de caché) para blindar la arquitectura subyacente.
