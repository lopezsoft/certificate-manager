# 🚀 Primeros Pasos con MATICERTS

Bienvenido a la documentación oficial de **MATICERTS API**. Nuestra arquitectura REST unificada (v1) está diseñada para integradores que buscan escalar la emisión y gestión de certificados digitales sin fricciones técnicas.

---

## 🌍 Entornos Operativos

Disponemos de infraestructuras separadas para garantizar que tus pruebas no afecten datos productivos. Parametriza la base URL en tu aplicación (`{{URL}}`) apuntando al entorno deseado:

:::danger Buenas Prácticas de Arquitectura
**Nunca "hardcodees" las URLs en el código fuente.** 
Utiliza variables de entorno (ej. `.env`) para parametrizar la conexión y permitir la transición fluida de *Sandbox* a *Producción* sin requerir nuevos despliegues ni refactorizaciones.
:::

## 🔐 Autenticación Segura (OAuth 2.0)

MATICERTS requiere que todas las peticiones (excepto endpoints públicos) estén firmadas con un **Bearer Token**.

### Métodos Soportados

<Tabs groupId="auth-methods">
  <TabItem value="m2m" label="Integración Backend (M2M)" default>
    <p>
      Para sistemas automatizados (ERP, CRM, Cronjobs), utiliza un <strong>Personal Access Token (PAT)</strong>. 
      Estos tokens se generan directamente desde el panel de administración de MATICERTS, no expiran por defecto y garantizan el mayor rendimiento.
    </p>
  </TabItem>
  <TabItem value="frontend" label="Aplicaciones Cliente">
    <p>
      Para portales que actúan en nombre de un usuario específico, obtén un token temporal vía login:
    </p>
    
```bash
curl -X POST "{{URL}}/api/v1/auth/login" \
     -H "Content-Type: application/json" \
     -d '{
           "email": "usuario@empresa.com",
           "password": "tu-contraseña-segura"
         }'
```
  </TabItem>
</Tabs>

## 🛠️ Tu Primera Petición

Inyecta tu token en el encabezado `Authorization` y realiza un *Health Check* para verificar tu conexión con nuestra infraestructura.

<Tabs groupId="programming-languages">
  <TabItem value="curl" label="cURL" default>

```bash
curl -X GET "{{URL}}/api/v1/sistema/health" \
     -H "Authorization: Bearer <TU_ACCESS_TOKEN>" \
     -H "Accept: application/json"
```

  </TabItem>
  <TabItem value="javascript" label="Node.js / Fetch">

```javascript
const response = await fetch('{{URL}}/api/v1/sistema/health', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer <TU_ACCESS_TOKEN>',
    'Accept': 'application/json'
  }
});
const data = await response.json();
console.log(data);
```

  </TabItem>
  <TabItem value="python" label="Python (Requests)">

```python
import requests

url = "{{URL}}/api/v1/sistema/health"
headers = {
    "Authorization": "Bearer <TU_ACCESS_TOKEN>",
    "Accept": "application/json"
}

response = requests.get(url, headers=headers)
print(response.json())
```

  </TabItem>
</Tabs>
